BUILD THE APK
Upload this folder to GitHub, open the Actions tab, wait for "Build APK", download the Riya-APK artifact.
(Or open in Android Studio > Build > Build APK(s).)

FIRST RUN - tap the buttons in the app in order
1 Allow microphone, contacts, calls & notifications
2 Allow lock screen (Device admin)
3 Allow display over other apps
4 Allow background running (battery)  -> choose Allow
5 Enable WhatsApp auto-send (Accessibility) -> Riya WhatsApp auto-send -> On
6 SAVE NAME & START (type any name first, e.g. Jarvis)

AI (FREE, FAST): in the app, paste a free Groq key from console.groq.com/keys into the AI BRAIN box.

LOOK: night-indigo theme with an animated voice orb; icons are vector drawables in res/drawable.

TELUGU: tick "Telugu mode" in the app. Offline needs the offline speech + Telugu voice packs downloaded on the phone.

COMMANDS (start with the name you set in the app, default Riya)
lock screen | open camera | open YouTube | open Spotify
play <song> | play <song> on YouTube
call <name>   (asks whom if several match)
send WhatsApp to <name> saying <message>
flashlight on / off
volume up / down / max / mute / 50
what's the time | what's the date
stop
